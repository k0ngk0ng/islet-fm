# 星屿收音机 · ISLET FM

一个零依赖的音乐星空互动玩具。点击夜空种下信标，旋转的扫描光束经过它们时，会根据高度、频道和位置生成一段循环旋律。

## 开始游玩

直接打开 `index.html`，或在目录里启动任意静态文件服务：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 操作

- 点击 / 触摸夜空：添加声音信标，并开始扫描
- `Space`：播放或暂停
- `R`：随机漫游到一片新星群
- `C`：清空当前频道
- `1` / `2` / `3`：切换暮色、深海、晨光频道
- 拖动扫描频率：改变循环速度

作品使用 Canvas 2D 绘制星空、轨道、星座和粒子，并通过 Web Audio API 实时合成所有声音；没有外部字体、图片、音频、框架或网络请求。当前星群会保存在浏览器本地。
